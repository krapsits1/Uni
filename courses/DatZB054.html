// patstāvīgais darbs
1. Studēt OWASP WSTG (Web Security Testing Guide) rokasgrāmatu. 2. Izvēlēties tīmekļa lietotni un veikt tai drošības testēšanu atbilstoši OWASP WSTG, dokumentēt iegūtos rezultātus. 3. Veikt papildu uzdevumu risināšanu, kas tiek piedāvāti praktiskajās nodarbībās.

# Tēma Piezīmes
01 Ievads, Tīmekļa tehnoloģiju zināšanu atsvaidzināšana Kursa saturs un pamati
02 Tīmekļa drošības pamati, uzbrukumi lietotņu loģikai, ievades validācija, Burp Suite Vide, rīki, ievainojamību klasifikācija
03 Nedrošas tiešās objektu norādes (IDOR), neaizsargāts saturs —
04 Klientpuses uzbrukumi, starpvietņu skriptēšana (XSS) Atstarotie XSS
05 Starpvietņu skriptēšana un aizsardzības mehānismi Saglabātie XSS
06 Starpvietņu pieprasījumu viltošana (CSRF) —
07 Sesiju pārvaldība, nepietiekama žurnalēšana un uzraudzība —
08 Serverpuses uzbrukumi, ceļa šķērsošana, attālinātā koda izpilde (RCE) —
09 Datņu iekļaušana, čaulu iegūšana Web / reverse / bind shells
10 Datņu augšupielādes ievainojamības RCE caur augšupielādi
11 OWASP Tīmekļa drošības testēšanas rokasgrāmata (WSTG) —
12 SQL injekcijas — pamati Auth bypass, datu zagšana
13 UNION SQL injekcijas Datu zagšana no nesaistītām tabulām
14 Aklās SQL injekcijas Automatizēta datu zagšana
15 Retāk sastopamas ievainojamības XXE, ORM, NoSQL, nedroša deserializācija
16 Jaunas ievainojamības, izaicinājumi Uzbrukumi reālām lietotnēm
// studiju rezultāti
Zināšanas: izskaidro tīmekļa lietotņu biežākās ievainojamības, pieejas to atklāšanai un novēršanai. Prasmes: praktiski veic ievainojamību atklāšanu un ekspluatēšanu (black-box); pielieto OWASP WSTG sistemātiskai drošības testēšanai un dokumentēšanai. Kompetences: identificē ievainojamību cēloņus, radītos draudus un to mazināšanas iespējas.
